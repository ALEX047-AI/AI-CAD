# Mistral AI в AI-CAD Desktop

По умолчанию приложение использует `https://api.mistral.ai/v1` и `mistral-large-latest` через OpenAI-совместимый Chat Completions API. Ключ Mistral берётся только из `MISTRAL_API_KEY` при запросе. Поле ключа в интерфейсе предназначено для режима Cloud. Ключ не записывается в проект, журнал, архив или исходники.

## Windows PowerShell: ключ только для текущего сеанса

Откройте PowerShell в каталоге проекта. Команда ниже запрашивает ключ без отображения и задаёт переменную только для этого окна:

```powershell
$secure = Read-Host 'Mistral API key' -AsSecureString
$pointer = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
try { $env:MISTRAL_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($pointer) }
finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($pointer) }
python run.py
```

Для собранного приложения замените последнюю строку на `dist\AI-CAD\AI-CAD.exe`. Не передавайте значение ключа в аргументах командной строки и не сохраняйте его в файле проекта. Если ключ был опубликован в переписке, замените его у провайдера.

## Использование

1. Выберите **Mistral**. Проверьте адрес и модель.
2. Нажмите **Проверить подключение**. Кнопка делает только запрос списка моделей; задание и проект не отправляются.
3. Установите флажок разрешения отправки. При запросе в API уходят текст задания, текущий граф проекта (узлы, параметры, ссылки), ID выбранного элемента и геометрическая сводка. Встроенные BREP-данные импортированных тел исключаются из запроса.
4. Введите инженерное задание. CAD-план проверяется на копии проекта. Ошибочный план получает одну попытку исправления с диагностикой; текущая модель меняется только после успешного построения всего пакета.
5. Пояснение плана и выполненные действия видны в журнале; запросы остаются в истории текущего сеанса. Настройки и ключ в JSON проекта не записываются.

Режим **Auto** пробует разрешённый Mistral, локальную Ollama и затем офлайн-парсер. Офлайн-парсер поддерживает ограниченные русские фразы и полный структурированный JSON-протокол операций.

Ошибки авторизации, лимита API и тайм-аута показываются в интерфейсе. Отсутствие ключа или разрешения не блокирует ручное и офлайн-моделирование.
