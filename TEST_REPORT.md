# Отчёт об испытаниях AI-CAD Desktop

## Происхождение сведений

Исторические протоколы относятся к отдельным этапам разработки и окружениям. Они не заменяют запуск тестов для текущего публикуемого архива.

## Исторические проверки

В предыдущих этапах сообщалось о выполнении тестов параметрического ядра, структурированных команд, сохранения и экспорта. Отдельные результаты относятся к Linux-среде; состав зависимостей и число проверок менялись между архивами.

**Текущий статус:** полный набор тестов данного исправленного комплекта здесь повторно не запускался. Новые числовые результаты не заявляются.

## Рекомендуемая проверка

```powershell
python -m pytest -q
python -m aicad.mvp_demo --output demo_output/mvp
python run.py
```

## Протокол испытания

Для каждой проверки записать: дату, версию Python, операционную систему, зависимости, точную команду, ожидаемый результат, фактический результат и путь к артефактам. Для Windows EXE отдельно проверить запуск на чистой системе.

## Критерии

Корректная геометрия, неизменность модели после отклонённой команды, повторное открытие проекта, воспроизводимость экспорта, отсутствие блокировки GUI и диагностируемые ошибки.
