# Состояние выпуска AI-CAD Desktop

## Доступно в исходном коде

Параметрическая модель на базе CadQuery/OpenCascade, инструменты построения и редактирования, сохранение проекта, структурированные CAD-команды, элементы AI-интеграции и тестовые сценарии.

## Требует подтверждения

- Запуск полного интерфейса на целевой Windows-машине.
- Упаковка и установка Windows EXE.
- Реальные запросы к внешним AI-провайдерам.
- Корректность всех сложных CAD-операций на разнообразных моделях.

## Статус публикации

Исходный код является материалом для проверки. Публичный релиз допускается после анализа лицензий и секретов, сверки с Git-репозиторием и испытаний на целевой платформе.

Не следует обозначать этот комплект как полностью готовый промышленный CAD-продукт.
