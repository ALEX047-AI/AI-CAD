# Сборка и проверка Windows EXE

Исходный код подготовлен для Windows, однако успешная сборка и запуск исполняемого файла должны подтверждаться отдельно на Windows.

## Подготовка

1. Установить Python 3.11 либо согласованное окружение Conda/Miniforge.
2. Установить зависимости из `requirements.txt` и необходимые средства упаковки.
3. Проверить запуск `python run.py` до сборки.
4. Из корня проекта запустить предусмотренный скрипт `build_windows.ps1` после просмотра его содержимого.

## Особое внимание

PySide6 может включать дополнительные компоненты QtWebEngine, не нужные приложению. Бездумное включение всех модулей через `--collect-all PySide6` способно привести к ошибкам ресурсов Qt. Необходимо собирать только используемые компоненты и проверять бинарные зависимости OpenCascade/OCP.

## Проверка результата

- EXE запускается без Python, установленного отдельно.
- Открывается главное окно, работают основные CAD-инструменты.
- Создание, сохранение, повторное открытие и экспорт модели выполняются без ошибок.
- Отсутствие AI-ключа не блокирует ручное моделирование.
- Все ошибки записываются и воспроизводятся.

Пока эти проверки не выполнены, статус Windows EXE — **не подтверждён**.
