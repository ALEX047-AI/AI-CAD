# AI-CAD Desktop

**AI-CAD Desktop** — настольная система параметрического трёхмерного моделирования. Проект объединяет ручное редактирование CAD-моделей и выполнение структурированных команд, подготовленных AI-подсистемой. Основная целевая платформа — Windows.

## Возможности исходного проекта

- Построение эскизов и объёмных элементов с использованием CadQuery и OpenCascade/OCP.
- Параметры модели и упорядоченная история операций.
- Операции построения и изменения геометрии, доступные через общий CAD-исполнитель.
- Сохранение проекта, импорт и экспорт инженерных форматов.
- Локальная обработка части текстовых команд и адаптеры внешних AI-провайдеров.

**Важно:** наличие функции в исходном коде не означает, что она полностью проверена на Windows. Текущие ограничения перечислены в `KNOWN_ISSUES.md`, а подтверждённые испытания — в `TEST_REPORT.md`.

## Технологии

Python 3.11, PySide6, CadQuery, OpenCascade/OCP. Зависимости устанавливаются из `requirements.txt`; для испытаний может потребоваться `requirements-dev.txt`.

## Запуск из исходного кода на Windows

Откройте PowerShell в корне проекта и выполните:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run.py
```

При отсутствии подходящей сборки CadQuery для выбранной среды используйте проверенное окружение Conda/Miniforge и инструкции проекта. Успешность установки зависит от версий бинарных зависимостей.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Для воспроизводимой проверки без графического интерфейса предусмотрен модуль `aicad.mvp_demo` (при наличии всех зависимостей):

```powershell
.\.venv\Scripts\python.exe -m aicad.mvp_demo --output demo_output/mvp
```
